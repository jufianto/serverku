## Context

Users of `serverku` currently rely on external SSH clients to connect to their provisioned VMs. To do so, they must inspect the project state to find the external IP address and remember the path to the SSH key generated by `serverku` (`~/.serverku/keys/serverku_rsa`). We want to streamline this by providing a native `serverku ssh` command.

## Goals / Non-Goals

**Goals:**
- Provide a `serverku ssh <project-name>` command.
- Automatically look up the project's running VM IP address.
- Automatically use the correct `serverku` private SSH key.
- Provide a seamless interactive terminal session.

**Non-Goals:**
- We will not implement a native Go SSH client (e.g., using `golang.org/x/crypto/ssh`) for the interactive session. Instead, we will wrap the system's `ssh` binary. It's much more robust for handling terminal resizing, colors, and standard SSH config.
- We will not support tunneling or port forwarding natively in this command yet (users can still do this via standard `ssh` if needed).

## Decisions

**1. Using `os/exec` vs Native Go SSH:**
We will use `exec.Command("ssh", ...)` and bind `os.Stdin`, `os.Stdout`, and `os.Stderr` to it.
- *Rationale*: A full interactive SSH client with proper PTY handling, window resizing, and escape sequences is complex to build perfectly in pure Go. Wrapping the existing system `ssh` command guarantees native behavior.

**2. SSH Key Handling:**
The command will read the private key path from the `store` (which already has logic for this: `store.GetSSHPrivateKeyPath()`).

**3. Username:**
The default user created by the provisioner is always `serverku`. We will hardcode `serverku@<ip>` as the connection target.

## Risks / Trade-offs

- **[Risk] Missing system `ssh` binary** → *Mitigation*: The command should return a clear, user-friendly error if `exec.LookPath("ssh")` fails, telling the user they need to install an SSH client.
- **[Risk] Project is not running** → *Mitigation*: The command will check the project state. If the IP address is empty or status is not running, it will abort with a clear error.
